# Phase 6G 规格：动效即空间模型

2026-11-26 grill-me 对齐确认，在 Phase 6D–6F 之后进行。

总原则：**动效只用来说明东西从哪来、到哪去、和什么相连，不做装饰。** 同级切换（空间之间、主从布局切换选中项、设置子页之间）保持 1 帧内瞬间完成，与 Finder 侧栏、Mail 切换邮件一致。

现状核查：

- 浮层（弹窗、命令面板、菜单、斜杠补全、Toast）进出均走弹簧且可打断；导航与 Tab 指示条弹簧滑移；预览画布缩放与交叉溶变已打磨（design-system.md §8.2）。
- 进入工作室为 `translateX(14→0)` + 淡入，退出只有 `240ms` 淡出，进出不对称。
- 列表增删、折叠区块展开收起、题库分组折叠均为一帧跳变，只有箭头旋转。
- 浮层一律从自身中心缩放（`scale(0.94→1) + translateY(-6→0)`），`transformOrigin` 从未设置。
- 6 档弹簧（`SPRING_GENTLE` 无人使用，`springTo`、`pageTransition` 基本闲置），另有约 40 处 `ms(100/120/140/150)` 写死在业务代码中；`reduceMotion()` 判断散落各处，降级方式不一。
- 拖拽排序（`studio/reorder.ts`，大纲、样例、比赛题目顺序共用）松手时 `offset` 直接归零，再以 `easeOut 180ms` 让位，被拖行先跳回原位再滑到新位置。
- 设置子页切换带 `translateY(4→0)` 150ms 微移（`SettingsView.tsx`），属于同级切换。

本规格落地后同步改写 [design-system.md](../design-system.md) §8（场景表、Token、降级规则）与 §8.3（拖拽排序、`animateLayout` 用法）。

---

## 1. 层级进出：对称

应用中唯一的「进入下一层」是空间 → 工作室（题目 / 比赛、代码片段、TRD 三种，均经 `App.tsx` 的 `SpaceStage`）。

- 退出是进入的倒放：工作室 `translateX(0→14)` + 淡出，与进入同一弹簧（`SPRING.smooth`），中途可打断并从当前位置折返。
- 下层空间保持静止，不做视差（避免两层同时全屏变换带来的离屏缓冲开销）。
- 返回按钮、`Esc`、快捷键走同一路径。
- 设置子页切换去掉 `translateY` 微移，改为瞬间完成。

## 2. 结构变化：非虚拟列表与折叠区块

范围：折叠区块（已归档比赛、设置中的 JSON、6D 的 Disclosure）与非虚拟列表的增删（比赛、代码片段、TRD、样例、分组）。虚拟列表（题库、命令面板）保持瞬间变化。

实现基于 `ViewRef.animateLayout`：只作用于调用它的视图及被它推动的兄弟节点，不波及整次提交，支持物理弹簧参数；**不负责插入与删除本身**，因此：

- **删除行**：该行先淡出（`DURATION.base`），再移除，同时对容器调用 `animateLayout(SPRING.standard)`，下方行上移。
- **新增行**：以透明状态插入，容器 `animateLayout` 让下方行下移，再淡入。
- **展开 / 收起**：区块自身高度与被推开的兄弟节点参与动画；内容区 `overflow: hidden` 并淡入淡出。
- 不使用 `LayoutAnimation.configureNext`（作用于整次提交，会误伤编辑器与预览）。
- **前置验证**：实现前实测 `animateLayout` 不触发编辑器 / 预览重排、弹簧参数按 Token 生效。不满足则本节整体不做，不退化为写死时长的 easeOut。

## 3. 浮层：从锚点长出

| 类别 | 打开 | 关闭 |
| :--- | :--- | :--- |
| 有锚点（菜单、斜杠补全、分体按钮下拉、导出菜单） | `transformOrigin` 设在靠近触发元素的角（向下对齐左边 → 左上角；向上翻转 → 左下角），`scale(0.96→1)` + 淡入，无 `translateY` | `DURATION.fast` 纯淡出，不缩放 |
| 居中（弹窗、命令面板） | 中心 `scale(0.96→1)` + 淡入，无 `translateY` | 同上 |
| Toast | 右下角上滑 6px + 淡入（不变） | 同上 |

- 打开走 `SPRING.standard`。浮层是临时物，关闭比打开快、不倒放；与 §1 层级进出的严格对称区分。

## 4. 动效 Token（`apps/desktop/src/ui/tokens/motion.ts`）

| Token | 取值 | ζ | 用途 |
| :--- | :--- | :--- | :--- |
| `SPRING.quick` | 500 / 39 | 0.872 | 主按钮按压 `scale(0.97)` |
| `SPRING.standard` | 400 / 35 | 0.875 | 浮层打开、指示条、结构变化、拖拽归位 |
| `SPRING.smooth` | 300 / 31 | 0.895 | 侧面板、抽屉、工作室进出 |
| `DURATION.fast` | 100ms | — | 浮层关闭淡出 |
| `DURATION.base` | 120ms | — | 悬停 / 按压底色、图标淡入淡出、删除行淡出、NavRail 跨组淡出 |

- 时长档统一用 `EASE_STANDARD`。
- **有出处的例外**（留在原文件，在 §8 表格注明）：预览画布交叉溶变 90ms、`Ctrl+滚轮` 缩放阻尼约 120ms、品牌页开场动效（EXPO 曲线）。
- 删除 `SPRING_GENTLE`、`springTo`、`pageTransition` 与 `colorTransition` 的时长参数；`motion.ts` 只保留基于 Token 的过渡构造函数。
- `uxPerf.test.tsx` 的阻尼带校验改为检查这 3 档。
- 新增检查测试：`ui/` 下除 `tokens/` 与上述例外文件外，出现 `transitionDuration: ms(<数字>)`、手写 `spring(…)` 或直接调用 `reduceMotion()` 即失败（与 6D 对颜色、字号的检查同法）。

## 5. 拖拽松手：续接速度、零跳动

`studio/reorder.ts`：

- 松手瞬间，将被拖行的 `translateY` 设为其相对新槽位的偏移，视觉上停在原处；随后以 `SPRING.standard` 弹到 0，初速度取松手前约 50ms 内的指针位移速度。
- 其余行让位改用 `SPRING.standard`，去掉 `easeOut 180ms`。
- 全程只动 `transform`；乐观顺序（`pending`）逻辑不变。

## 6. 减少动态效果

按作用分三类，在 `tokens/motion.ts` 中集中处理，业务代码不再判断 `reduceMotion()`：

| 类别 | 降级 |
| :--- | :--- |
| 空间位移（工作室进出、浮层缩放、指示条滑动、拖拽归位） | 取消位移；工作室与浮层改为 `DURATION.base` 纯淡入淡出；指示条、拖拽直接就位 |
| 结构变化（展开收起、行增删） | 瞬间变化，删除行不先淡出 |
| 颜色反馈（悬停、按压底色、图标淡入淡出） | 保留 |

品牌页开场动效不变（直接显示终态）。

## 7. 执行顺序与验收

每步一个 jj 提交；提交前跑通与 `.github/workflows/lint.yml` 一致的本地检查。

1. **文档同步**：改写 design-system.md §8、§8.3。
2. **Token 与降级**（§4、§6）：新建 `tokens/motion.ts`，替换全部调用点，加检查测试；含慢放开关。
3. **层级进出**（§1）。
4. **浮层锚点**（§3）。
5. **拖拽松手**（§5）。
6. **结构变化**（§2，含前置验证）。
7. **验收**：
   - 开发专用环境变量 `XCPC_MOTION_SLOW=<倍数>`，在 `tokens/motion.ts` 统一换算：时长 × 倍数，弹簧刚度 ÷ 倍数²、阻尼 ÷ 倍数（阻尼比不变，曲线等比拉长）；release 构建不读取。
   - 10 倍慢放逐项录屏：工作室进入、退出、中途打断折返；各类浮层从锚点长出、翻转方向、关闭；展开收起与行增删；三处拖拽松手；开启「减少动态效果」后再走一遍。
   - 按 §8.4 用 release 构建录 Trace：工作室进出、行增删的 60Hz 掉帧率 `< 2%`。
   - 录屏与 Trace 放临时目录，不进仓库，交用户确认。

## 8. 明确不做

- 同级切换（空间、主从选中项、设置子页、Tab 内容）的任何过渡动画。
- 工作室进出的下层视差或变暗。
- 虚拟列表（题库、命令面板）的行级动画。
- 浮层关闭时的缩放倒放。
- 装饰性动效：循环、呼吸、成功态弹跳、彩带等。
- `LayoutAnimation.configureNext`；写死时长的 easeOut 退化方案。
