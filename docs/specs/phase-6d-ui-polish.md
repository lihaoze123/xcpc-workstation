# Phase 6D 规格：底层设计系统收敛与重点界面精修

2026-11-26 grill-me 对齐确认。Phase 6A–6C 之后，功能与流畅度已基本到位，但界面的「精致感」仍不足。经实机截图与代码统计，根因不在单个页面，而在**同一件事有多种做法**：同一个切换控件两种变体随意混用、各页手写页头高度不一、10–15pt 之间挤了 11 档字号、间距/圆角/控件高度各有十几种字面量、图标 16 种尺寸且线宽随尺寸漂移、语义色大面积铺色、层次只靠 1px 线导致画面「平」。

因此本阶段**先统一底层系统，再精修重点界面**（题库、比赛、出版工作室、训练总览）；其余界面只做 Token 迁移与原型套用，不做结构重设计。

本规格落地后需同步改写 [design-system.md](../design-system.md) 的 §3–§5、§9、§9.1（见 §9 文档同步清单），以本规格为准取代其中冲突条目。

## 2. 底层 Token（`apps/desktop/src/ui/tokens/`）

新建 `tokens/` 目录，集中导出下列 Token；业务组件只能引用 Token，不得再写字面量。

### 2.1 字号（`type.ts`）

| Token | 字号 / 行高 | 字重 | 用途 |
| :--- | :--- | :--- | :--- |
| `micro` | 11 / 14 | 600 | 键帽、徽章、热力图坐标 |
| `caption` | 12 / 16 | 400 | 元信息、次要说明、表头、副信息 |
| `body` | 13 / 19 | 400 | 正文、列表行、按钮、输入框、菜单 |
| `strong` | 14 / 20 | 600 | 区块标题、卡片标题 |
| `title` | 18 / 24 | 600 | `DetailHeader` 标题 |
| `display` | 26 / 30 | 600 | 训练页大数字（`tabular-nums`） |

- **字重只用 400 与 600**，取消 500 与 700。层级靠字号、颜色、字重三选一拉开，不叠加。
- 编辑器字号由用户设置决定，题面纸张由 Typst 排版，二者不受本表约束。

### 2.2 间距、圆角与尺寸（`metrics.ts`）

- **间距刻度**：`2 · 4 · 6 · 8 · 12 · 16 · 20 · 24 · 32`。`6` 用于图标与文字的紧凑间距，`20` 即 `GUTTER`；`3 / 5 / 7 / 10 / 13 / 14 / 18 / 28` 按语境归并到就近档。
- **圆角**：`4`（徽章、键帽）、`6`（按钮、输入框、列表行、菜单行）、`8`（胶囊轨道、菜单与弹出层外框）、`12`（卡片、对话框、内嵌面板）、`full`。嵌套圆角一律用 `inner(outer, padding)` 计算，不写字面量。
- **控件高度只有三档**：

  | 档 | 高度 | 用于 |
  | :--- | :--- | :--- |
  | `sm` | 24 | 卡片头、表格行内的图标按钮与胶囊 |
  | `md` | 28 | 工具行内一切：搜索框、按钮、胶囊（**工具行按钮由约 32 降到 28**） |
  | `lg` | 32 | 对话框底部按钮、菜单行、命令面板行 |

- **行高**：列表行 `40`，表格行 `36`，菜单行 `32`；工具行 `TOOLBAR = 52` 不变。

### 2.3 图标（`Icon.tsx`）

- `size` 改为枚举 `"sm" | "md" | "lg"`，分别为 `14 / 16 / 20`，去掉 `number`。`sm` 配 `sm 24` 控件与表格行内，`md` 为默认，`lg` 用于导航栏、对话框头部图标方块与空状态图标方块（空状态不再出现 28 / 32）。
- **恒定视觉线宽 1.5px**：`Icon.tsx` 按尺寸自动设置 `strokeWidth = 1.5 × 24 / size`（14 → 2.57，16 → 2.25，20 → 1.8），调用方不得再传 `strokeWidth`。
- 品牌页 icon 与动效不在此列。

### 2.4 护栏测试

- 新增 `apps/desktop/src/ui/tokens.test.tsx`（随 `nsh test` 运行）：扫描 `src/ui/**/*.tsx` 中的 `fontSize`、`fontWeight`、`gap`、`padding*`、`margin*`、`borderRadius`、控件 `height` 字面量与 `<Icon size=…>`，出现 Token 以外的值即失败。
- 允许单行豁免：同一行或上一行写 `// token-exempt: <原因>`，原因不得为空。典型豁免：品牌页动效几何、热力图方格、图表绘制坐标。

## 3. 表面层次：内嵌浮层面板

取代 design-system §4「结构分割只用 1px 细实线，不加外阴影」。

- **外壳**：标题栏与左侧导航在 `--bg-canvas` 上。
- **内容面板**：导航右侧整个工作区是**一块** `--bg-surface` 圆角面板，四周距外壳 `8`（左侧贴导航），圆角 `12`，`1px --border-subtle` + 环境阴影 `0 1px 2px rgba(0,0,0,0.035)`；暗色为外壳 `#09090B`、面板 `#111113`，加 `sheet-rim` 提亮内描边。
- 列表-详情型的列表栏与详情栏**都在面板内**，中间只用 `1px` 线分隔；列表栏也是白底，选中行用 `--bg-selected`。
- **出版工作室同样套用**：去掉导航后编辑器、预览舞台、属性抽屉都在面板内；预览舞台 `--bg-paper-stage` 是面板内部的凹陷区。
- 列表-详情型的详情区内**不再套卡片**；卡片只出现在单页型（训练、工具）与设置的分组区块里。

## 4. 页面原型与页头

所有空间强制套用三种原型之一。**页头只能用 `Toolbar` / `DetailHeader`，禁止手写页头高度。**

| 原型 | 适用 | 结构 |
| :--- | :--- | :--- |
| **列表-详情型** | 题库、比赛、模板、设置 | 左栏顶部 52pt `Toolbar`：左为搜索与筛选，右为次操作（描边）与「新建」（主按钮）；右栏顶部 `DetailHeader`，底线与左栏工具行平齐。设置的分组导航即其「列表」。列表栏不放「N 场比赛」之类的计数。 |
| **单页型** | 训练、工具 | 顶部 52pt `Toolbar`：左为导航级下划线 Tab，右为页面级参数（胶囊）与主操作；内容区统一 `GUTTER`，最大宽度 `1120` 居中。 |
| **工作室型** | 出版工作室、TRD、片段编辑器 | 全屏、无导航，标题栏即页头。本阶段只改标题栏（§7），不改结构。 |

---

## 5. 切换控件分工

同一 `Segmented` 组件的两种变体按**角色**使用：

- **下划线 Tab = 导航级（换一块内容）**：训练「总览 / 比赛日历 / 提交 / 题解」、编辑器「题面 / 样例 / 题解」、模板「算法库 / 模板册」、题库详情子页。单页型放在 52pt 工具行左侧，底线与工具行分割线重合。
- **胶囊分段 = 参数级（换一种看法）**：时间范围、热力图模式、Rating 平台、主题模式、对话框选项等。
- **唯一例外**：出版工作室标题栏的「题面 / 出题」切的是整个工作室的模式，按规则属导航级，但保留胶囊。
- **一个卡片头最多一个胶囊。**

## 6. 横跨所有列表的显露规则

1. **空值什么都不画**：不画点、不画「—」、不写「未评级」。没有任何评级时，比赛页的难度分布整块不显示。删除 `library/cells.tsx` 中为保持节奏而画的空状态小点。
2. **整列都空就不显示该列**：判定范围是整个工作区（不是当前筛选结果），切换筛选时列不会忽隐忽现；一旦有一道题填了难度，该列固定出现。
3. **复选框按需显露**：列宽始终预留（零抖动），只在行悬停、该行已选中或当前存在任意选中项时绘制；键盘多选照常可用。

---

## 7. 语义色面积

**语义色只用于小面积标记，不用于大字和大面积底色。**

- `display` 大数字一律用主文本色；段位色退到旁边的小 `RatingBadge` 或 6pt 圆点。
- 图表里的段位色只画在线上：Rating 曲线按所处段位分段着色；去掉铺满背景的段位色带，改为 Y 轴左侧 3pt 宽色条示意段位区间。
- **热力图改用品牌鸭青蓝 5 阶**；绿色只留给「AC / 通过」语义。
- 品牌色维持现状：只用于实色主按钮、指示条、聚焦环，不做浅色衬底。

## 8. 重点界面

### 8.1 题库（列表-详情型）

**列表：从表格改为列表**，左栏固定约 `440`pt，余下全给详情。

- 去掉表头行；排序移入「筛选」菜单底部的单选组「排序：标题 / 难度 / 最近修改」，非默认排序时按钮上显示一个小点。
- 工具行只留 4 个元素：分组侧栏开关、搜索（弹性宽度）、「筛选」、右侧「+」。
  - 「筛选」合并原「标签 / 难度 / 筛选」三个下拉，一个菜单分三组。
  - 「导入 Polygon」收进「+」的分体菜单（新建题目 / 导入 Polygon 包），取代 design-system §9.1 第 3 条中独立的描边按钮。
  - 有筛选生效时，工具行下方出现一行 28pt 可移除 chip（如 `难度 1600–1900 ×`）与「清除」；无筛选时该行不存在。
- 行结构为 40pt 单行：复选槽（§6.3）、题名（`body`，弹性宽度，单行省略）、标签（`caption` 次级色，最多 2 个加 `+N`，空间不足时先被截掉）、难度徽章（固定 44pt 槽）、状态图标（固定 16pt 槽）。两个固定槽遵守 §6.2。
- 分组侧栏（`GroupSidebar`）本阶段不改。

**详情：预览定位为阅读器。**

- 改为「适合宽度」+ 多页连续纵向滚动，纸张左右各留 16pt，页间距 12pt。
- 不显示缩放 HUD，不支持 `Ctrl+点击` 跳源码；缩放、翻页、跳转留在出版工作室。
- 灰色舞台保留为面板内凹陷，与工作室预览观感一致。

### 8.2 比赛（列表-详情型）

- 去掉「题目」「概况」区块标题与「3 题」计数。
- 题目列表去掉卡片外框，直接铺在面板上，行结构与题库一致：40pt 行；题号用 `strong` 等宽固定槽，然后是题名、限制（`caption`，`tabular-nums`）、难度槽；拖拽手柄悬停时显示。
- 「挑题」移到列表末行，做成浅色的「+ 从题库挑题」行，原位追加。
- 头部保持「编辑」主按钮、「定稿」描边按钮与 ⋯ 菜单。
- 难度分布：有评级时，在列表下方显示 6pt 高的分段色条加图例，无卡片、无标题；全部未评级时不显示。
- 左侧比赛列表行的第二行由「N 题」改为「日期 + 定稿锁」。

### 8.3 出版工作室标题栏

- **左侧**：`←`、面包屑、「题面 / 出题」胶囊。比赛内面包屑为 `比赛名 › A. 题名`，比赛名用 `caption` 次级色，可点击返回比赛；单题只显示题名。
- **右侧**：「预览栏」「属性抽屉」两个**纯图标**开关成组（间距 2；开为 `--bg-selected` 底 + 主文本色图标，关为次级色图标；tooltip 写名称与快捷键），间隔 8 后接「导出 PDF ▾」主按钮。
- **去掉标题栏里的「专注」按钮**，专注模式本身保留：入口为 `Ctrl+Shift+F` 与命令面板。它同时收起比赛大纲、隐藏预览并开启打字机滚动，**不与两个开关自动合并**。

### 8.4 训练总览（单页型）

- **工具行**：左为下划线 Tab「总览 / 比赛日历 / 提交 / 题解」；右为时间范围胶囊（仅「总览」时出现）、「同步」图标按钮、「记一题」主按钮。同步中按钮变成转圈；「上次同步」时间只放在 tooltip 里，不在界面常驻。
- **概览带**：把各 OJ 的 Rating 卡与 3 张 KPI 卡合并为**一张卡片**，横排「AtCoder / Codeforces / 过题 / 连续 / 今日」。每格为 `caption` 标签 + `display` 数字（主文本色）+ `caption` 副信息（如「最高 4229」「7157 次提交」，旁边一个段位色小点）；格间只用间距分隔。去掉「周期内过题」旁的范围小徽章。
- **热力图**：固定为最近 12 个月滚动窗口（GitHub 式），**去掉年份切换**，只保留「每日题数 / 每日最高难度」一个胶囊；删除「悬停或点击方格查看当日明细」这行字；不受时间范围影响（热力图看习惯，范围筛选看成绩）。
- 下面两行（Rating 曲线 + 难度趋势、难度分布 + 标签分布）结构不变，只套用 §2 Token 与 §7 配色。
- 改完后总览从约 10 张卡减为 5 张。

### 8.5 其余界面

设置、工具、模板（算法库 / 模板册）、命令面板、对话框、Toast：**只做 Token 迁移与原型套用**（含设置 48pt、工具 44pt 页头换成 `Toolbar`，模板与片段编辑器的切换控件按 §5 重新分配），不做结构重设计。

## 9. 执行顺序与验收

每步一个 jj 提交；提交前跑通与 `.github/workflows/lint.yml` 一致的本地检查。

1. **文档同步**：按本规格改写 `docs/design-system.md`，包括 §3（语义色面积）、§4（内嵌面板，删除「不加外阴影」）、§5（字号、间距、圆角、高度、图标 Token，取代原密度标尺）、§9.1（三原型与页头硬规则、切换控件分工、空值显露规则、题库列表形态与「+」分体菜单、工作室标题栏）、§6.1（训练总览新结构，热力图改为最近 12 个月）。
2. **Token 与全量迁移**：新增 `ui/tokens/` 与 `tokens.test.tsx`；用机械化脚本把字面量映射到最近档，再人工复核边界（如 `10` 归 8 还是 12）；`Icon` 改为枚举尺寸 + 恒定线宽。**一次性全量迁移**，不逐页进行，避免新旧刻度并存。
3. **骨架**：实现内嵌面板；所有页头换成 `Toolbar` / `DetailHeader`；切换控件按 §5 重新分配；落实 §6 显露规则与 §7 语义色规则。
4. **题库**（§8.1）。
5. **比赛**（§8.2）。
6. **出版工作室标题栏**（§8.3）。
7. **训练总览**（§8.4）。
8. **验收**：用 `tests/fixtures/olymp-ref/contest-zh/workspace` 与带训练数据的工作区，把 6 个空间、出版工作室、命令面板、一个对话框在浅色与深色下各截一张（约 18 张），迁移前后并排人工对比。截图放在临时目录，不进仓库，也不沉淀为脚本。

**第 2、3 步完成后先停下**，把截图交给用户确认方向，再继续第 4–7 步。

## 10. 明确不做

- 设置、工具、模板、命令面板、对话框、Toast 的结构重设计；分组侧栏改版。
- 题库详情的原生文本渲染（预览仍走 Typst，保持「看起来一样」）。
- 换用新的视觉风格（侧栏半透明、毛玻璃外壳等）；Token 之外的新配色。
- UI 截图回归脚本或 CI 截图比对。
- 热力图年份回看、自定义改键。
