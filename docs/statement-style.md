# 题面样式与出版

## 1. 默认主题 `olymp-classic`：1:1 复刻 `GassaFM/olymp.sty`

`olymp-classic` 是默认主题。验收标准是与真实的 `olymp.sty` PDF **逐像素视觉对齐**（借助 `render_page_png` 做回归比对）。

### 1.1 精确复刻清单

1. **纸张与版心**：默认 A4（`210mm × 297mm`）。页边距左右 `15mm`、上下 `20mm`。支持双面装订偏移 `binding-offset`，并自动为奇偶页补白页。
2. **页眉与页脚**：页眉左侧是赛名，右侧是日期/地点，下方一条 `0.4pt` 细实线；首页和封面不显示页眉。页脚为 `Page X of Y`（中文为 `第 X 页，共 Y 页`）。
3. **居中题头与限制表**：题名居中、大字号、加粗（`Problem A. Title`）。紧接着是**居中的紧凑双列限制表**：`Input file` / `Output file` / `Time limit` / `Memory limit`，可选附加气球颜色和作者。
4. **章节标题不孤立**：`Input`、`Output`、`Interaction`、`Examples`、`Note` 一律设置 `sticky: true`。
5. **样例表**：`0.4pt` 黑色实线边框；默认 50/50 双列，列宽可调；表头为加粗等宽字体的 `standard input` / `standard output`；**跨页时自动重复表头**（`table.header(repeat: true)`）；空行和前导空格原样保留。
6. **中西文混排**：启用标准的中西文间距和标点挤压。完整支持 `\epigraph`、`\illustration` 等 `olymp.sty` 经典语义。

### 1.2 封面与试题列表页

新建比赛默认带**独立封面页 + 试题列表页**（经典 ICPC / CCPC 正式题册），可以在样式检查器里一键关闭：

- 顶部居中放赛事 Logo（可选）；
- 主标题和副标题居中、大号、加粗，下面依次是主办方/作者、日期与地点；
- 居中的简洁题表：题号 A/B/C…、题名、时间限制、内存限制、起始页码；
- 页尾标准声明：`本试题册共 N 题，M 页。如果您的试题册缺少页面，请立即通知志愿者。`（英文版用官方对应的句式）。

### 1.3 字体与回退链

| 用途 | 首选 | 回退 |
| :--- | :--- | :--- |
| 西文正文与数学 | `New Computer Modern` | — |
| 西文标题 | `CMU Sans Serif` | — |
| 样例与代码 | `CMU Typewriter Text` | — |
| 中文正文 | 方正书宋 | 思源宋体（Source Han Serif SC） |
| 中文粗体标题 | 方正黑体 | 思源黑体（Source Han Sans SC） |
| 引言与作者 | 方正楷体 | 思源宋体 / 黑体 |
| 封面主标题 | 方正小标宋 | 思源宋体 |

字体通过 `fontdb` 从系统读取。缺少某个字体时自动回退到下一个，不弹出提示。v1 实际使用的字体名列表见 `reference/v1_lib.typ`。

## 2. 三层渐进式主题定制

- **Layer 1：预设主题库**，包括 `olymp-classic`（默认，1:1 复刻）、`modern-xcpc`、`noi-classic`、`minimal-editorial`。
- **Layer 2：可视化样式检查器（背后是 `theme.toml` Token）**，不写代码就能实时调整纸张边距、系统字体、题头对齐、限制表样式、样例表边框与列宽、封面 Logo/水印和中英文词条。主题可以在工作区级（`themes/*.toml`）定义，也可以在比赛级（`contests/<id>/theme.toml`）覆盖。
- **Layer 3：高级 Typst 插槽或源码覆写**，支持局部命名插槽（`cover-slot`、`header-slot`、`before-problem-slot`、`footer-slot`），也支持整个模板覆写。

## 3. 题面体检与印刷前预检（`xcpc-lint`）

规则在 Rust 侧执行，耗时在毫秒级。检查结果既会在出版工作室的状态栏实时提示（只在有问题时出现），也通过 MCP 工具提供给 Agent 自动修复。

- **排版与数学规范**：`<=` / `>=` / `!=` 没有写成 `\le` / `\ge` / `\ne`；中西文与公式之间缺空格；同一题面中变量大小写混用（如 `$N$` 和 `$n$`）；样例为空，或带有异常的尾随空白。
- **印刷前预检（Preflight）**：配图分辨率过低（`< 300 DPI`）；文本或公式超出版心宽度；双面装订模式下奇偶页分布和补白页不正确；题表与实际题目数量、页码不一致。

## 4. 代码模板册（TRD）

复用 Typst 引擎和出版工作室，把 `templates/` 下的算法模板排版成纸质的 Team Reference Document：

- **多栏紧凑排版**：可以在 2 / 3 / 4 栏之间切换；自动生成章节目录；带语法高亮；头部的复杂度和用法注释会被渲染出来；**不设页数硬上限**。
- **KACTL 风格的 6 位哈希**：每段代码右上角印一个 6 位短哈希，计算时先去掉注释和空白字符。赛场上手敲完长模板后，可以比对哈希来防笔误。

## 5. 双语题面校对与语义级 Diff

- **双语同题**：`statement.zh.md` 和 `statement.en.md` 共用 `samples/`、`limits` 和 `assets/`。出版工作室按需展开双语并排校对视图，中文和英文题册可以分别导出。
- **语义级 Diff**：以工作区 Git 历史或已冻结的比赛快照为基准，按题目章节（描述 / 输入 / 输出 / 样例 / 限制）展示变更对比，方便命题组赛前终审。
- **双语一致性校验（MCP）**：比对中英文题面中的变量、数据范围和边界条件，标出漏改或前后矛盾的地方。
