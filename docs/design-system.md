# 界面设计系统

本文定义 NSH 应用界面的信息架构和视觉语言。组件**以 `nsh/base` 为基础**（需要时可以基于 NSH 自己写组件，不引入第三方 UI 组件库），主题通过 `nsh/base` 的主题/Token 机制实现；[`hero-nsh`](https://c-w-xiaohei.github.io/hero-nsh/)（HeroUI 风格）只作样式参考，不作为依赖。快捷键写作 `Cmd`，在 Linux 上对应 `Ctrl`。题面纸张的样式见 [statement-style.md](./statement-style.md)。色板和布局骨架可以在 [`reference/color_system_preview.html`](./reference/color_system_preview.html) 中交互式查看。

## 1. 设计理念

整体风格是**现代极简的「精密工具」风**，融合 Linear / Zed / Craft 的精密感和 HeroUI 式的柔和层次（柔和圆角、细腻的边框和层次投影、克制的高对比排版）。

1. **内容优先，界面退让**：界面本身用低饱和的中性灰，不与纯白的 A4 题面纸张和算法语义色争抢注意力。
2. **精密与克制**：用 1px 清晰边框建立结构秩序，用微圆角和极轻的投影化解生硬感；所有数字严格等宽对齐（`tabular-nums`）。
3. **高频操作无阻碍**：动效时长 120–180ms，绝不拖慢键盘操作和实时排版校对（唯一的长动效例外是无工作区时的品牌页开场动效，见 §8.5）。
4. **让布局说话（Layout Over Labels）**：空间位置和排版形态本身能表达含义的地方，就不再叠加多余的标题和解释文案；严禁在界面上暴露开发者实现细节和无意义的技术指标（见 §7）。同理，不用 `·`、`|` 这类分隔符和装饰性的分隔线来隔开并列的内容，交给间距和对齐（界面和出版物都如此；题面册继承自基准的页眉页脚横线除外）。
5. **日常零打扰、首次有温度**：日常使用对熟手零打扰；只有「第一次」时刻（无工作区时的品牌页、内置示例）才提供一次性的品牌展示与引导。

## 3. 色彩系统

基底是纯净的中性灰（Zinc），品牌主色是 **深鸭青蓝（Deep Petrol / Teal-Blue，`H:195°`）**，浅色/深色自动跟随系统。

### 3.4 语义色面积约束（Phase 6D）

**语义色只用于小面积标记，不用于大字和大面积底色：**

- `display` 大数字一律使用主文本色（`--text-primary`）；段位色退到旁边的小 `RatingBadge` 或 `6pt` 圆点。
- 图表中的段位色只画在线上：Rating 曲线按所处段位分段着色；去掉铺满背景的段位色带，改为 Y 轴左侧 `3pt` 宽色条示意段位区间。
- **热力图统一使用品牌鸭青蓝 5 阶（`H:195°`）**；绿色只留给「AC / 通过」语义。
- 品牌主色只用于实色主按钮、指示条与聚焦环，不做浅色衬底。

## 4. 材质、圆角与层级

- **表面层次：内嵌浮层面板**（Phase 6D）：
  - **外壳**：标题栏与左侧导航位于 `--bg-canvas`（浅色 `#FAFAFA` / 暗色 `#09090B`）上。
  - **内容面板**：导航右侧整个工作区是一块 `--bg-surface`（浅色 `#FFFFFF` / 暗色 `#111113`）圆角面板，四周距外壳 `8pt`（左侧贴导航），圆角 `12px`，`1px --border-subtle` 边框 + 环境阴影 `0 1px 2px rgba(0,0,0,0.035)`；暗色下额外叠加 `sheet-rim`（`rgba(255,255,255,0.12)`）提亮内描边。
  - **列表-详情型**：列表栏与详情栏共享同一块内容面板，中间只用 `1px --border-subtle` 细实线分隔；列表栏同样为 `--bg-surface` 底，选中行用 `--bg-selected`；详情区内**不再套卡片**。
  - **出版工作室**：同样套用内嵌面板，去掉导航后大纲、编辑器、预览舞台与属性抽屉都在面板内，各栏间用 `1px --border-subtle` 细实线分隔；预览舞台 `--bg-paper-stage` 作为面板内部的凹陷区。
  - **卡片使用范围**：卡片只出现在单页型（训练、工具）与设置的分组区块里。
- **圆角刻度**（与 `metrics.ts` 对齐）：

  | 元素 | 圆角 |
  | :--- | :--- |
  | 徽章 / Tag / 键帽 | `4px` |
  | 按钮 / 输入框 / 列表行 / 菜单行 | `6px` |
  | 胶囊轨道 / 菜单与弹出层外框 | `8px` |
  | 卡片 / 对话框 / 内嵌面板 | `12px` |
  | 预览区悬浮胶囊 HUD / 圆形指示点 | `full`（`9999px`） |

- **嵌套圆角要同心**：`内圆角 = 外圆角 − 内边距`，一律通过 `inner(outer, padding)` 计算，不写字面量。例如卡片圆角 `12px`、内边距 `4px`，那么内部的选中项或按钮圆角是 `8px`。
- **立体层次与分层材质**：
  - 普通卡片用 `1px` 细边框加极轻的环境阴影 `0 1px 2px rgba(0,0,0,0.035)`（暗色 `rgba(0,0,0,0.24)`）；强投影只留给拖拽替身与模态弹窗。
  - **模态弹窗、命令面板、下拉菜单与 Tooltip**统一使用**高不透明度实色表面**（`--bg-surface` / `--bg-elevated`）+ 清晰 `1px` 边框 + 暗色模式下 `1px` 提亮内描边（`sheet-rim: rgba(255,255,255,0.12)`），保证锐利度与帧率；模态蒙层亮色用 `rgba(9,9,11,0.12)`、暗色用 `rgba(0,0,0,0.48)`。
  - **预览区悬浮胶囊 HUD** 使用轻度毛玻璃（`backdrop-blur: 12px`）加半透明背景与暗色 `1px` 内描边，让纸张边缘自然透出。
- **统一自绘窗口顶栏**：采用 `TitleBarStyle::Hidden` 并为顶栏及弹窗背景蒙层设置 `.window_drag(true)`，左右留出窗口安全区，确保打开弹窗或浮层时窗口拖动依然不被锁死。

## 5. 字体排印与信息密度

- **UI 字体**：西文优先 `Inter`（可随应用打包），其次是系统无衬线字体；中文依次匹配 `Source Han Sans SC` / `Noto Sans CJK SC`。
- **代码、样例和源码编辑**：优先 `JetBrains Mono` / `Maple Mono` / 系统等宽字体，连字开关可以配置。
- **数字**：Rating、时空限制、题号计数、页码和表格统计一律使用 `font-variant-numeric: tabular-nums`。
- **底层 Token 体系（`apps/desktop/src/ui/tokens/`，Phase 6D）**：业务组件一律引用 Token，不得写字面量，由 `apps/desktop/src/ui/tokens.test.tsx` 护栏测试强制校验（仅允许带原因的 `// token-exempt: <原因>` 单行豁免）。
  - **字号刻度（`type.ts`）**：

    | Token | 字号 / 行高 | 字重 | 用途 |
    | :--- | :--- | :--- | :--- |
    | `micro` | `11 / 14` | `600` | 键帽、徽章、热力图坐标 |
    | `caption` | `12 / 16` | `400` | 元信息、次要说明、表头、副信息 |
    | `body` | `13 / 19` | `400` | 正文、列表行、按钮、输入框、菜单 |
    | `strong` | `14 / 20` | `600` | 区块标题、卡片标题 |
    | `title` | `18 / 24` | `600` | `DetailHeader` 标题 |
    | `display` | `26 / 30` | `600` | 训练页大数字（`tabular-nums`） |

    - **字重只用 `400` 与 `600`**，取消 `500` 与 `700`。层级靠字号、颜色、字重三选一拉开，不叠加。
    - 编辑器字号由用户设置决定，题面纸张由 Typst 排版，二者不受本表约束。

  - **间距、圆角与尺寸（`metrics.ts`）**：
    - **间距刻度**：`2 · 4 · 6 · 8 · 12 · 16 · 20 · 24 · 32`（`6` 用于图标与文字的紧凑间距，`20` 即 `GUTTER`）。
    - **圆角刻度**：`4 / 6 / 8 / 12 / full`，嵌套圆角一律用 `inner(outer, padding)` 计算。
    - **控件高度三档**：

      | 档 | 高度 | 用于 |
      | :--- | :--- | :--- |
      | `sm` | `24` | 卡片头、表格行内的图标按钮与胶囊 |
      | `md` | `28` | 工具行内一切：搜索框、按钮、胶囊 |
      | `lg` | `32` | 对话框底部按钮、菜单行、命令面板行 |

    - **行高与工具行**：列表行 `40`，表格行 `36`，菜单行 `32`，工具行 `TOOLBAR = 52`。

  - **图标（`Icon.tsx`）**：
    - `size` 为枚举 `"sm" | "md" | "lg"`，分别对应 `14 / 16 / 20`（不接受任意数字）。`sm` 配 `sm 24` 控件与表格行内，`md` 为默认，`lg` 用于导航栏、对话框头部图标方块与空状态图标方块。
    - **恒定视觉线宽 `1.5px`**：按尺寸自动计算 `strokeWidth = 1.5 × 24 / size`（`14 → 2.57`，`16 → 2.25`，`20 → 1.8`），调用方不得再传 `strokeWidth`（品牌页 icon 与动效不在此列）。

## 6. 关键界面

### 6.1 训练总览（单页型，5 卡结构）

采用单页型原型（内容区统一 `GUTTER`，最大宽度 `1120` 居中），总览收敛为 **5 张卡片**，不加多余的副标题和技术指标：

- **工具行（`52pt` `Toolbar`）**：左为导航级下划线 Tab「`总览 / 比赛日历 / 提交 / 题解`」；右为时间范围胶囊（仅「总览」时出现）、「同步」图标按钮与「记一题」主按钮。同步中按钮变为转圈；「上次同步」时间只放在 tooltip 里，不在界面常驻。
- **概览带（1 张卡）**：将各 OJ 的 Rating 卡与 3 张 KPI 卡合并为**一张卡片**，横排「AtCoder / Codeforces / 过题 / 连续 / 今日」。每格为 `caption` 标签 + `display` 数字（主文本色、`tabular-nums`）+ `caption` 副信息（如「最高 4229」「7157 次提交」，段位色退为旁边小 `RatingBadge` 或 `6pt` 圆点）；格间只用间距分隔，不放范围小徽章。
- **滚动 12 个月热力图（1 张卡）**：固定为最近 12 个月滚动窗口（GitHub 式），**去掉年份切换**，右上角仅保留「每日题数 / 每日最高难度」单个胶囊；删除「悬停或点击方格查看当日明细」说明文案；不受时间范围筛选影响；统一使用**品牌鸭青蓝 5 阶（`H:195°`）**（绿色仅留给 AC / 通过语义），Hover 显示当天明细。
- **趋势与分布（下方两行）**：Rating 曲线 + 难度趋势、难度分布 + 标签分布，全部套用 §3.4 与 §5 规范（Rating 曲线按段位分段着色并采用 Y 轴左侧 `3pt` 色条示意段位区间，去掉铺满背景的色带；难度分布柱状图支持点击柱子直接筛选对应区间）。

### 6.2 出版工作室预览画布

- **画布**：使用 `--bg-paper-stage`，视觉上完全退后。
- **A4 纸张**：始终显示为纯白（`#FFFFFF`），带双层纸张投影（近处细描边 + 远处柔和扩散）和 `1px` 极淡的纸边。只有单页模式。支持缩放和平移（触控板双指无级缩放）；`Ctrl+点击` 页面跳到编辑器里对应的源码行。
- **底部悬浮毛玻璃胶囊 HUD**：居中，距画布底部 `16px`，包含以下控件：
  `[ - | 100% | + | 适合宽度 ]`、`[ ‹ 3 / 12 › ]`、`[ Preflight 状态徽章 ]`（无问题时不显示）。HUD 常驻，不自动淡出。

### 6.3 品牌页、Icon 与「关于」（Phase 2.5）

- **品牌页与首次体验**：
  - **出现时机**：没有可打开的工作区时显示的页面就是品牌页（首次启动，或记住的工作区已失联）；有工作区时冷启动直达上次对象，不会看到这一页。**不做独立启动页、不做每次启动的动画、不做轮播、不放 slogan。**
  - **布局尺寸**：
    - 应用 icon `144px` 居中；
    - 下方 `20px`：字标「**XCPC** Workstation」，`26px`，`XCPC` 粗体，`Workstation` 次级色（`--text-secondary`）、常规字重；
    - 再下方 `28px`：三个入口纵向排列，宽 `240px`、高 `36px`、圆角 `8px`、间距 `8px`：「新建工作区」（主色按钮）、「打开已有文件夹」、「打开示例」（描边按钮）；

- **创建即设背景色（Phase 2）**：窗口创建时即设置背景色 `bg-background`（对应 `--bg-canvas`），杜绝 GTK 默认白底闪屏。

### 6.5 关键时刻反馈（按触发方式划界：后台静默 + 就地确认 + 单槽克制 Toast）

全应用按**触发方式与操作耗时**划界——**后台自动发生的保持静默；用户主动点按触发的动作结束时一律给明确反馈，零宽度跳动、绝不堆叠或遮挡**：

1. **后台 / 持续性操作（保持静默）**：
   - 题面自动保存、实时排版编译、文件监听热刷新、首次编译成功等后台行为静默完成，只在出错或耗时超过 `150ms` 时温和提示。
2. **显式短点按 / 写入 / 复制 / 局部运行（触发控件原位瞬态确认 `1.4–1.8s`）**：
   - 导出 PDF（`✓ 已导出`）、手动点按「保存」代码/配置（`✓ 已保存`）、更新生成批次（`✓ 已更新`）、复制复现命令 / MCP 配置 / 诊断信息 / 带样例 Markdown（`✓ 已复制`）、设置页应用自定义路径 / 重新检测工具链（`✓ 已应用` / `✓ 已刷新`）、出题面板「运行选中」局部运行（`✓ 完成`）等，在触发控件原位短暂确认后自然恢复，锁定最小宽度防止布局抖动，不弹 Toast。
3. **长耗时异步任务 & 菜单 / 快捷键触发的结果类动作（右下角单槽克制 Toast）**：
   - 适用范围：比赛批量检查 / 全部重新检查、比赛与单题内存检查、试跑验题人代码、单题全量检查、菜单触发的「导出检查报告」等。
   - **位置与形态**：窗口右下角单行浮条（预览可见时自动上移避开右下角缩放条）；全局仅保留一个槽位，新通知平滑替换旧通知，不堆叠；通过类消息（如「比赛检查通过，可以定稿」「内存检查完成，没有发现问题」「验题人代码：alice 全部通过（3 题）」「已导出检查报告」）`3s` 自动收起；发现问题类消息（如「检查完成：2 题有问题」）附「查看」入口直达对应状态浮层，`4.5s` 自动收起；鼠标悬停暂停倒计时；用户手动取消不弹 Toast。
4. **里程碑 / 状态跃迁（就地状态落定 + 克制的下一步衔接）**：
   - **全量检查通过**：列表 / 大纲中的通过标记保持极淡灰勾（避免满屏绿勾抢眼）；状态位（`StatusSlot`）与 Toast 中的「已通过 / 可以定稿」使用低饱和成功色勾（`#15803D` / `#4ADE80`），静态下也能一眼确认；状态词与状态位规则见 [specs/authoring-ui-refactor.md](./specs/authoring-ui-refactor.md) §2–§3；
   - **出错与环境缺失**（如没有找到 C++ 编译器）：提前在状态位就地说明并给出「去设置」，执行类操作不得落到「操作没有完成」这类泛化文案，也不插入推动布局的横幅（见同一规格 §6）；
   - **比赛定稿与重新编辑**（内部概念名为「冻结 / 解冻」，界面一律写「定稿 / 重新编辑」）：定稿后比赛名旁出现与全局图标集一致的线性锁图标（`140ms` 淡入），左侧比赛列表行第二行显示「日期 + 定稿锁」，详情头标题旁显示「已定稿」标记；属性抽屉淡为只读，只留「重新编辑」入口；「定稿」按钮 tooltip 说明后果：「存一份定稿：之后题库里的修改不再影响这场比赛」；重新编辑前确认框列出与定稿时不同的题目和文件；
   - **加入比赛 / 批量清理 / 脏输入修复**：加入比赛后在原行原位短暂确认并可直达所属比赛；批量清理未引用素材或一键修复脏输入后，在原位置短暂交代处理数量（可撤销操作附带「撤销」）。
- **导出分体按钮（Phase 2 / 3B）**：
  - 主按钮恒定为「导出 PDF」（不变成「在文件夹中显示」）；点击导出耗时 `> 150ms` 时按钮内部显示进度，导出完成后就地短暂显示 `✓ 已导出` 约 `1.8s` 后恢复「导出 PDF」（全程零宽度跳动）。
  - 下拉箭头菜单（`▾`）上半段固定 3 项：`导出题面册` / `导出题解册` / `在文件夹中显示`（PDF 过期时标注次级色「较旧」，从未导出时置灰）；**Phase 3B 起**在分割线下方追加 `导出 DOMjudge 包` 与 `导出 Hydro 包`。`Cmd+K` 同步提供上述导出动作以及 `导入 Polygon`。

## 7. 文案克制规范

1. **靠视觉自我解释，去掉冗余标签**
   - 空间位置和排版形态已经能说明功能的区域（左侧题目列表、中间编辑区、右侧纸张预览、热力图方块等），**不加区块标题或括号说明**。例如不要写「结构化编辑器」「比赛大纲」「题目描述 (Legend)」。
   - 后台与持续性操作成功保持静默：实时编译正常、校验通过、自动保存成功时，不显示「编译成功 / Linter 通过 / 已保存」之类的徽章；只在出现错误、警告或耗时超过感知阈值（> 150ms）时温和提示。用户主动发起的显式产出操作（如「导出 PDF」）可在触发按钮就地短暂给出克制的成功反馈（如 `✓ 已导出` 约 1.8s 后恢复，零宽度跳动，见 §6.5）。
   - **写它是什么、做什么，不写内部概念名**：「冻结」对用户不可理解，界面写「定稿 / 重新编辑」；开关写清作用（「补空白页，方便双面打印」而不是「补白页」）；页码写「第 n 页」而不是裸数字。「出版工作室」「出版开关抽屉」这类规格里的称呼只用于文档，界面上一律不出现；按钮直接写动作（「编辑」而不是「在出版工作室打开」），面板直接写内容（「属性」而不是「出版设置」）。
2. **不泄露技术实现**
   - 主工作区里**禁止出现**底层技术名词、配置文件名和工程遥测指标，例如 `SQLite FTS5`、`增量编译 12ms`、`theme.toml`、`MCP Ready`、`NSH Canvas`。
   - 这些信息统一放到「设置 → 开发者 / 高级 / MCP 集成」二级页面，按需查看。主工作区只使用竞赛选手和命题人熟悉的领域语言。
3. **错误文案三段式与语气**
   - **三段式结构**：先用人话说明现象，再给可点击的定位，**只在有明确下一步时才写下一步**。
   - **隐藏底层细节**：主界面不显示错误码与英文原文，这些放进「复制详情」（Phase 2 错误组件预留入口，Phase 2.5 文案集中到 Core 供 GUI 与 CLI 中文输出共用，`--json` 与 MCP 保留结构化错误码）。
   - **克制语气**：不道歉、不拟人、不用感叹号。
   - **规则拒绝不当错误**：定稿只读等业务规则拒绝不按报错处理，改用次级文本色陈述事实，并附上对应操作入口（如「重新编辑」）。

## 8. 动效与流畅感（Fluidity）

整体手感基调为 **温润物理弹簧**（融合精密工具的干脆与原生弹簧的轻柔呼吸感）：结构性变化采用 NSH 原生平台线程 **`Animated.spring` / `Motion` / `spring(...)`**（阻尼比收敛至 `ζ = 0.86–0.90`，过冲 `≤ 1%`，温润不弹跳，随时可打断且保留速度；NSH `spring(...)` 自计时，不额外设置截断物理尾段的硬 `transitionDuration`），高频打字、滚轮与捏合保持零滞后跟手。

| 场景 | 节奏 | 曲线 | 约束 |
| :--- | :--- | :--- | :--- |
| 按钮 Hover / 聚焦 / 按压 | `120–160ms` / 弹簧自计时 | 纯色主按钮 `SPRING_PRESS`（`ζ ≈ 0.87`）；其余指数缓动 | 按压 `scale(0.97)` **仅限纯色主按钮（`primary`）**；描边/幽灵按钮、图标按钮、导航项、菜单与列表行仅做底色过渡、不做缩放 |
| Tab 指示条 / 左栏选中滑块 | 弹簧自计时 / `120ms` | NSH 原生 `spring`（`ζ ≈ 0.87`） | 绝对定位滑块平滑滑移，随时可打断；NavRail 仅在同组相邻项（题库 ↔ 比赛）之间滑移，切到或离开「设置」时改为 `120ms` 原地淡出 + 目标处淡入 |
| 页面 / 设置子页 / 进出工作室 | 弹簧自计时 | NSH 原生 `spring`（`ζ ≈ 0.90`） | 空间连续性纯 GPU 位移（空间切换 `translateY(6→0)`、进入工作室 `translateX(14→0)` + `opacity`，规避 GTK4 全屏 `scale` FBO 重采样，零闪白） |
| 定稿锁图标出现 / 消失 | `140–160ms` | 柔和缓动 | 淡入淡出，与全局线性图标同形 |
| 面板收折 / 出版开关抽屉 | 弹簧自计时 | NSH 原生 `spring`（`ζ ≈ 0.90`） | 优先 `transform` / `opacity`，不挤压编辑器重排 |
| `Cmd+K` / 弹窗 / 菜单 / 补全浮层 | 弹簧自计时 | NSH 原生 `spring`（`ζ ≈ 0.88`） | `scale(0.94→1) + translateY + opacity` 温润浮出 |
| 拖拽排序（组卷 / 样例） | 实时跟手 | 目标位置显示细蓝线 | 松手后 `180ms` 归位 |
| `Ctrl+滚轮` 缩放插值 | `~120ms` | 指数阻尼（`1 - exp(-dt/32)`） | 光标锚点像素锁定，随时可被捏合/滚动打断 |

全局遵守系统的 `prefers-reduced-motion` 设置：开启时降级为瞬间切换或纯淡入淡出。本章中**唯一允许突破上限的长动效例外**是无工作区品牌页的开场动效（约 `1.53s`，见 §8.5）。

### 8.1 流畅感工程铁律（Compositor-First & Zero-Jitter）

以下规则作为桌面端 UI 实现的硬约束（与「不能有 1px 布局抖动」同级）：

1. **连续手势严格合成器优先**：缩放、平移、拖拽排序等高频连续手势期间，**只更新 GPU 合成器 `transform`（`translate` / `scale`）**，禁止每帧修改布局尺寸（`width`/`height`/`padding`）或反复调用 `scrollTo` 与布局竞态；手势结束时单次原子提交布局状态与滚动偏移。
2. **输入 1 帧内乐观响应（≤ 16ms）**：点击、切换 Tab、切题、键盘导航（`J/K`、`Cmd+1..6`、`Cmd+K`）必须在当前帧给出视觉状态变化，绝不等待磁盘 I/O、SQLite 查询或 Typst 编译返回才更新激活态；高频交互绝不阻塞编辑器打字。
3. **零闪白、零整树重建**：切换题目、切换「题面 / 题解」、筛选列表或重新编译时，保留旧画面（或列表滚动位置）直到新数据/新图层首帧就绪，**禁止先清空状态闪一下白画布**；动态列表必须稳定 `key`，复用已有视图。
4. **面板与浮层优先 `transform` + `opacity`**：侧栏、抽屉、浮层显隐避免逐帧改宽导致正文与编辑器文字反复折行抖动。
5. **可打断性**：任何程序化动画（如平滑跳页、滚轮缩放阻尼）一旦收到用户新的滚轮、捏合、拖拽或按键，必须立即终止并无缝接管当前位置，不与用户抢控制权。

### 8.2 纸面预览画布手感标准（Phase 2 补齐，详见 [specs/perf-ux-observability.md](./specs/perf-ux-observability.md)）

- **缩放**：两阶段合成器缩放（手势期纯 `transform` 锚定视口光标，离散滚轮做 ~120ms 指数阻尼，触控板捏合 1:1 跟手，结束时单次原子提交并清晰化分块）。
- **渐进式预览与交叉溶变**：自适应输入节拍（停顿 `35/65ms` 快出帧、连打按上次编译耗时合批）；主路径严格视口页优先，视口稳定后后台可取消预热相邻页（`[max+1, min-1, max+2]`）进共享像素缓存；同页更新在 `PageImage` 内走 `90ms` 原生 `transition_opacity` 交叉溶变（旧层托底防闪白，首帧 0ms 直出）。
- **切题 / 切题解零闪白与视口记忆**：切换目标或「题面 / 题解」时保留旧页画面（至多轻度淡化）直到新首帧就绪，并按 `(target, id, book)` 记忆 `{ zoom, scrollY, panX }`。大纲切题拆成两次提交：点击只提交高亮（INP `≤ 16.6ms`），编辑器、属性与预览在该帧上屏后再替换（`afterNextPaint`）；连点时只构建最后一题。编辑器按文件保留最近 8 个实例（LRU）：非当前的叠放并 `visibility: hidden`（不用 `display: none`，否则 NSH 会拆掉原生视图、回访时重建行），只读且交出焦点；切回时撤销栈、光标与滚动原样保留，期间磁盘有改动则作为一次可撤销编辑并入。
- **比赛内按题号跳页**：同场比赛内点击 `A / B / C` 时直接使用 NSH 原生帧时钟 `scrollTo({ y, animated: true })` 做短时平滑滚动（可随时被手动滚轮打断）；跨比赛或单题切换则直接就位。
- **横向平移与拖拽轻惯性**：放大后使用嵌套横向 `<Scroll>` 获取原生横向惯性，边界柔和阻尼收住而非硬撞墙。

### 8.3 NSH 0.6 Linux 实践与避坑（参考 `gicek/safay`）

参考同栈 NSH 桌面产品 `gicek/safay` 的结构与交互打磨（保留本项目的深鸭青蓝 `H:195°` 色板、零装饰原则与成功态静默规范，不照搬其引导箭头、空态光环装饰及蓝色主色）：

1. **零抖动微交互**：
   - **聚焦环**：使用 `ring(1).ring_inset()`（纯阴影，占 `0px` 布局空间），绝不因边框切换撑宽或截断文字。
   - **按压微回弹**：**仅限纯色主按钮（`primary`）**按下时使用 `scale(0.97)` 温润微回弹（`ζ ≈ 0.87`，`prefers-reduced-motion` 下退化为纯底色变化）；描边/幽灵按钮、图标按钮、导航项、菜单、列表行与表格单元格保持底色反馈、不做缩放。
   - **零重排悬停与错误占位**：行内操作放绝对定位浮层或预留固定槽位；表单报错就地替换字段说明行（同一行、同一高度），不在底部预留空槽。
   - **下拉框即时收起**：`Select` 触发重操作时用 `set_timeout(0)` 延后执行，让下拉菜单在当前帧立即收起。
   - **键盘与指针零冲突（搜索 / 列表）**：搜索框保持焦点同时用 `When::Always` 监听上下键移动高亮行，仅越出视口时最小 `reveal()`；指针高亮仅监听 `on_mouse_move`（不用 `mouse_enter`），避免键盘滚动时静止光标反抢焦点；高亮行相邻分割线自动隐藏。
   - **零重排拖拽排序（组卷 / 样例）**：`4px` 拖动阈值防误触；起拖时一次性 `measure()` 缓存槽位网格；仅浮起替身订阅高频指针信号（列表行不重绘）；槽位交换走 `180ms EaseOut`；松手保留乐观顺序（`pending` 标记）直到异步落盘完成，防止回弹闪跳。
2. **NSH 0.6 Linux（GTK4 / GSK）原生能力与避坑**：
   - **优先原生帧时钟动效**：`Animated`、`transition_opacity` / `transition_transform` / `transition_colors` 与 `scrollTo({ animated: true })` 直接跑在 GTK `GdkFrameClock` 上（零 JS 往返、天然可打断、自动遵守 `reduce_motion`）。
   - **桌面分栏**：可拖拽多栏使用 `<ResizablePanelGroup>`，**不用 `<SplitView>`**（iPadOS 固定分栏）。
   - **Linux 缩放约束**：`<Scroll zoomTo / maximumZoomScale>` 在 Linux 是空操作，继续使用两阶段 GPU `transform` 缩放。
   - **禁止重面板动画改宽**：不要对编辑器或预览区等重面板使用 `LayoutAnimation` / `animateLayout` 动画改宽（每帧 `queue_allocate` 会导致正文反复折行卡顿）；抽屉走 `transform: translateX()` 浮层滑入，固定侧栏 0ms 单帧切宽 + 内部内容 `120ms` 淡入微移；`animateLayout` 只用于小槽位交换。
   - **`<Scroll>` 内图片溢出保护**：`<Scroll>` 内的 `<Image>` 必须设置 `overflow: hidden`，防止原图像素尺寸被计入滚动范围。
   - **长列表与热刷新**：`Cmd+K` 与题库长列表基于 `<Command filterable={false}>`（接 Rust 内存模糊 + Frecency 排序）与 `<DataTable>`（行列虚拟化）；`notify` 热刷新时通过 `EditorRef` 原地更新并保留光标与滚动位置，禁止重建 `<Editor>`。

### 8.4 UI 改动自检清单与离线可观测性

每次修改桌面端交互后，需结合无头门禁与真机 Trace 核对：
- 无头确定性门禁：`cd apps/desktop && nsh test`（含 `uxPerf.test.tsx` 校验弹簧阻尼带、信号零冗余重算、自适应节拍、相邻页预热与每格信号隔离）；
- 渲染性能门禁：`scripts/perf-gate.sh`（基于 `--profile bench-fast` 校验短卷/长卷编译与 2x 栅格化 P95）；
- 真机离线 Trace：通过 `XCPC_TRACE=1` 或「设置 → 关于 → 性能 Trace」录制并导出合并后的 Rust+JS Chrome Trace `.json`，配合 `python3 scripts/trace-analyze.py --gate <trace.json>`（必要时开 `NSH_FPS=1`）核对：
  - 连续手势（滚轮/捏合/拖拽）无抖动、无锚点漂移、60Hz 掉帧率 `< 2%`；
  - 切题、切 Tab、开关面板无闪白、无 1px 布局跳动、INP P95 `≤ 16.6ms`；
  - 动画中途操作能立刻打断接管；
  - 高频打字时预览与 UI 不卡顿。
  - 口径：INP 从输入量到「应用更新之后的下一帧开始」（双 rAF，含 NSH 提交、排版与布局）；掉帧按实测刷新周期计（帧间隔 `> 1.5 × vsync`），60Hz 掉帧为 `> 25ms`。录制期间 rAF 会让引擎线程每帧醒来，比率含空闲帧，优先看 INP 与卡顿总时长。
- 以 release 为准：dev 构建（`nsh run` / `nsh dev`）的 JS 与列表绑定比 `nsh run --release` 慢一个数量级（实测切题首访 85–116ms vs 11–21ms），dev 数字只用于归因、不用于判定是否达标。
- 卡顿归因：`scripts/nsh-perf.sh [--workspace <DIR>]`（`nsh run --trace`）复现同一操作后关闭应用，输出每次输入的「事件处理 JS / NSH 提交（含列表 JS）/ 挂载项」拆分与最贵的引擎轮次；离线日志可用 `python3 scripts/nsh-perf-summary.py <log>` 重新汇总。

### 8.5 唯一长动效例外：品牌页开场动效（Phase 2.5）

品牌页动效总时长约 **`1.53s`（0.75x 舒缓节奏）**，是 §8 中**唯一的长动效例外**（仅在无工作区品牌页播放一次；日常冷启动直达工作区，永不触发）：

1. **`0–960ms`**：底板与纸叠淡入并缓慢向左大角度扇开至终态（`−20° / −10° / 0°`）；
2. **`640–1400ms`**：黄色几何铅笔从右上方滑入落定；
3. **`900–1530ms`**：字标、三个入口与页脚依次错峰淡入并轻柔上移（指数缓动、零过冲，保持舒缓呼吸感）。

硬约束：
- 任意点击、按键或滚轮立即快进至终态；按钮在完全透明阶段（`opacity === 0`）不响应点击以避免盲点误触；「关于」页重播时三个工作区入口仅作展示、不切走当前已打开的工作区；
- 遵守 `prefers-reduced-motion`（开启时直接显示终态）；
- 动完静止，不做漂浮循环；**终帧 = icon**；
- 全程只动 `transform` / `opacity`，走 NSH 原生帧时钟；
- 在「关于」页点击 icon 直接重播同一「扇开 → 铅笔落定」动效。

## 9. 交互工艺细则

1. **渐进式显露与克制的空态**
   - 80% 的高频路径要极简直达。高级能力（Typst 插槽覆写、细粒度边距/字号、MCP 集成、外部 OJ 同步配置）放在抽屉或二级页里按需展开。
   - 空工作区、空比赛或没有搜索结果时，不写长篇引导文案，只留克制的视觉留白，加上 **1–2 个最直接的行动入口**（如「新建题目」「拖入 Polygon 包」，入口同时标出快捷键）。
2. **键盘和全局拖拽都是一等公民**
   - 所有流程都能脱离鼠标完成：`Cmd+K` 命令面板、`Cmd+1..6` 切换空间、`J/K` 或方向键浏览列表、`Esc` 逐层收起浮层或返回上级。只在键盘导航时显示鸭青蓝的 Focus Ring，鼠标点击时不显示。
   - 全局原生拖放：Polygon `.zip`、图片或 `.md` 拖进窗口后，自动识别意图并导入；题库中的题目可以直接拖进比赛里排序。
3. **光学对齐**：图标与文字并排、三角箭头居中等场景，以视觉重心为准，而不是机械的几何居中。
4. **零布局抖动，150ms 防闪烁**
   - Hover、选中、激活 Tab 都不能引起任何 `1px` 的宽度或高度跳变。例如不要靠切换 `font-weight` 来区分状态，因为加粗会撑宽元素；改用颜色、底色或预留宽度。
   - 耗时 `< 150ms` 的原生操作（搜索、增量编译、切题）**不显示 Loading**；加载指示器统一延迟 `150ms` 才出现。
5. **根据上下文智能粘贴**
   - 在编辑器里粘贴截图：自动保存到题目的 `assets/` 并插入规范的图片语法。
   - 在题库视图里粘贴 Codeforces / AtCoder / QOJ 题目链接：自动识别来源和原题 URL。
   - 在样例输入框里粘贴文本：自动清理不可见的 BOM 字符和多余的 `\r`。
6. **隐形引导与快捷键速查**
   - **只做被动层（Phase 2 起）**：tooltip（悬停 `600ms` 出现）右侧用 `kbd` 显示快捷键；`Cmd+K` 每个动作右侧显示快捷键；搜索/输入占位符带淡色 `Ctrl K`；空态入口标出快捷键。**不做任何根据用户行为触发的主动提示**（包括「`Ctrl K` 更快」）。
   - **快捷键速查（Phase 2.5）**：设置中提供「快捷键」分组按场景列出；在任意位置按 `Ctrl+/` 呼出同一张表的浮层，`Esc` 关闭；`Cmd+K` 也可搜到。速查表为**只读**，不做自定义改键。

## 9.1 图标、页面原型与组件规则（Phase 6D 收敛）

0. **同一元素切换时纹丝不动**：在同类对象间切换（选另一道题、另一场比赛）时，容器里多一项、少一项或文字变长，都不能让其他元素移位；可变内容放进固定高度的单行槽位里（裁切而不换行）。

1. **图标**：统一使用 Lucide 线性图标（ISC，原样放在 `apps/desktop/src/ui/icons/`，不自绘、不改形），以 `Image` + `tintColor` 着主题色；尺寸严格枚举为 `"sm" | "md" | "lg"`（`14 / 16 / 20`，默认 `md`，恒定视觉线宽 `1.5px`，详见 §5）。界面里不用 `← ☰ ▾ × ‹ ›` 之类的文字符号代替图标。同一含义只用同一个图标（锁、加号、删除等）。
2. **导航栏**：68pt 宽，图标在上、名称在下；题库、比赛在顶部，设置沉底；选中项为浅灰底 + 主文本色。
3. **页面原型与页头硬规则**：所有空间强制套用以下三种原型之一，**页头只能使用 `Toolbar` / `DetailHeader`，禁止手写页头高度**：

   | 原型 | 适用 | 结构 |
   | :--- | :--- | :--- |
   | **列表-详情型** | 题库、比赛、模板、设置 | 左栏顶部 `52pt` `Toolbar`（左搜索与筛选，右次操作与主按钮）；右栏顶部 `DetailHeader`（无副行元数据时保持 `52pt` 与左栏底线平齐，有副行元数据时自然折行）。设置的分组导航即其「列表」。列表栏不放「N 场比赛」之类的计数。主操作「编辑」为实色主按钮，其余为描边按钮，低频与危险操作收进 `⋯` 菜单。 |
   | **单页型** | 训练、工具 | 顶部 `52pt` `Toolbar`（左为导航级下划线 Tab，右为页面级参数胶囊与主操作）；内容区统一 `GUTTER`（`20pt`），最大宽度 `1120` 居中。 |
   | **工作室型** | 出版工作室、TRD、片段编辑器 | 全屏、无导航，标题栏即页头。 |

   - **切换控件（`Segmented`）分工**：
     - **下划线 Tab = 导航级（换一块内容）**：训练「总览 / 比赛日历 / 提交 / 题解」、编辑器「题面 / 样例 / 题解」、模板「算法库 / 模板册」、题库详情子页。单页型放在 `52pt` `Toolbar` 左侧，底线与工具行分割线重合。
     - **胶囊分段 = 参数级（换一种看法）**：时间范围、热力图模式、Rating 平台、主题模式、对话框选项等。
     - **唯一例外**：出版工作室标题栏的「题面 / 出题」切的是整个工作室的模式，按规则属导航级，但保留胶囊。
     - **一个卡片头最多一个胶囊**。
   - **横跨所有列表的显露规则**：
     - **空值什么都不画**：不画占位点、不画「—」、不写「未评级」。全部未评级时，比赛页难度分布整块不显示。
     - **整列都空就不显示该列**：判定范围为整个工作区（非当前筛选结果），切换筛选时列不会忽隐忽现；只要至少有一条记录非空，该列即固定出现。
     - **复选框按需显露**：列宽始终预留（零抖动），仅在行悬停、该行已选中或当前存在任意选中项时绘制；键盘多选照常可用。
   - **题库（列表-详情型）**：
     - **左栏从表格改为列表**（固定约 `440pt`，余下全给详情），去掉表头行；排序移入「筛选」菜单底部的单选组（`标题 / 难度 / 最近修改`），非默认排序时按钮显示小点。
     - 工具行仅留 4 个元素：分组侧栏开关、弹性搜索框、「筛选」（合并原标签 / 难度 / 筛选三个下拉为一个三分组菜单）、右侧「`+`」分体菜单（`新建题目 / 导入 Polygon 包`，取代原独立「导入 Polygon」描边按钮）。有筛选生效时，工具行下方出现一行 `28pt` 可移除 chip 与「清除」；无筛选时该行不存在。
     - 行结构为 `40pt` 单行：复选槽 + 题名（`body`，弹性单行省略）+ 标签（`caption` 次级色，最多 2 个加 `+N`，空间不足时优先截掉）+ 难度徽章（固定 `44pt` 槽）+ 状态图标（固定 `16pt` 槽）；两个固定槽遵守整列空值隐藏规则。
     - 详情预览定位为**阅读器**：适合宽度 + 多页连续纵向滚动（纸张左右各留 `16pt`，页间距 `12pt`），不显示缩放 HUD，不支持 `Ctrl+点击` 跳源码（缩放、翻页与跳转留在出版工作室）；灰色舞台保留为面板内凹陷区。
   - **比赛（列表-详情型）**：
     - 左侧比赛列表行第二行显示「日期 + 定稿锁」（不显示「N 题」）。
     - 详情去掉「题目」「概况」区块标题与「N 题」计数；题目列表去掉卡片外框直接铺在面板上，`40pt` 单行（`strong` 等宽固定题号槽 + 题名 + `caption` `tabular-nums` 限制 + 难度槽；拖拽手柄悬停时显示）；「挑题」移到列表末行作为浅色「`+ 从题库挑题`」原位追加。头部保留「编辑」主按钮、「定稿」描边按钮与 `⋯` 菜单。
     - 难度分布：有评级时在列表下方显示 `6pt` 高分段色条与图例（无卡片、无标题）；全部未评级时不显示。
   - **出版工作室标题栏（工作室型）**：
     - **左侧**：`←`、面包屑、「题面 / 出题」胶囊。比赛内面包屑为 `比赛名 › A. 题名`（比赛名用 `caption` 次级色，可点击返回比赛）；单题只显示题名。
     - **右侧**：「预览栏」「属性抽屉」两个**纯图标**开关成组（间距 `2pt`；开为 `--bg-selected` 底 + 主文本色图标，关为次级色图标；tooltip 写名称与快捷键），间隔 `8pt` 后接「导出 PDF ▾」主按钮。
     - **去掉标题栏中的「专注」按钮**，专注模式本身保留（入口为 `Ctrl+Shift+F` 与 `Cmd+K`，同时收起大纲、隐藏预览并开启打字机滚动，不与上述两个开关自动合并）。
4. **删除**：只放在 `⋯` 菜单，红色文字和图标，点击后弹出确认对话框（红色实底「删除」按钮 +「取消」）；仍被比赛引用时对话框直接说明原因，不给删除按钮。
5. **空态**：浅灰方块里的图标 + 一句话 + 一句次要说明 + 一个行动按钮（带快捷键）。
6. **对话框**：在窗口中垂直居中（略高于正中）；头部是图标方块 + 标题 + 一句说明；字段标签旁用淡色写约束（如「题目文件夹的名字，建好后不能改」），出错时这一行就地变成红字说明。按钮里不嵌快捷键徽标，快捷键放在 tooltip。
7. **菜单**：统一用 `Menu` 自绘的 32pt 行，左侧 16pt 图标或勾选列（14pt 勾），右侧快捷键；多选筛选菜单选择后不关闭。
8. **命令面板**：水平以窗口为中心，顶部位于标题栏下方并留出呼吸边距（不顶着标题栏上沿），行圆角与外框同心（`6px`），每行左侧图标，快捷键一律右对齐且自适应窗口宽度。
9. **设置页**：左栏分组导航（`工作区 / 排版 / 外观 / 快捷键 / 关于`）+ 右侧圆角卡片区，每组一个标题 + 一句用途说明；行内左侧内容、右侧操作；配置 JSON 默认折叠，主按钮是「复制配置」；「排版」分组用于配置工作区默认模板、按模板 `schema` 动态生成的默认参数（含一键还原），以及派生自定义模板和打开样式文件的快捷入口；「外观」分组包含界面语言（`跟随系统 / 简体中文 / English`，英文界面下为 `System / 简体中文 / English`，切换后当帧热刷新）、主题模式（`浅色 / 深色 / 跟随系统`）、编辑器字号/行高/连字与打开全局样式文件的入口；快捷键页提供顶部搜索过滤与右对齐键帽；关于页含检查更新（`nsh/updater`）与重播引导入口。
10. **编辑器（带样式的源码）**：保留 Markdown 标记但降为淡色；全程统一使用 `EDITOR_MONO`（`JetBrains Mono` + 思源黑体 CJK 回退）等宽字体，标题与粗体加粗，斜体倾斜，行内/块级公式保持中性墨色并配极轻底色（不使用蓝色主色避免喧宾夺主），代码与公式块整行浅灰底；样式范围由 Core 的 `markdown_spans`（与排版同一套 pulldown-cmark 解析）计算。全程只用一种字体：NSH 编辑器按自身字体计算折行，装饰里换更宽的字体会超出折行宽度被截断。顶部合并为单一 38pt 栏：左侧为「题面 / 样例 / 题解」分段标签，右侧仅保留 4 个高频插入图标（行内公式、公式块、表格、图片，配 tooltip 与快捷键），并支持 `Mod+F` 查找替换与诊断悬停/标尺提示。
11. **素材库（居中轻量 Gallery）**：采用一个居中弹窗、两种状态（**网格 ⇄ 放大**），无右侧详情栏与工具条。入口位于属性抽屉「素材 N 个」、Slash「插入图片」与 `Cmd+K`「素材库」（不新增全局快捷键）。网格态约 `880×72vh`，等宽方格（~168px，`contain` + 浅棋盘格底），下方一行显示文件名与大小（`tabular-nums`），未引用仅弱化标「未引用」，悬停右上角浮出插入/重命名/删除图标按钮（绝对定位零重排），顶部仅留「导入」（支持拖入）与「清理未引用（N）」（N=0 时隐藏）。点击方格或按 `Space` 原地共享元素过渡到放大态（`140–160ms`，可打断），`←/→` 切图、`Esc`/`Space` 返回网格，底部一行显示分辨率、大小与可点击的「引用位置」（点击跳编辑器对应行并关闭弹窗），提供「插入到光标处」主按钮与已引用图片的 50/75/100% 宽度预设。明确不做缩放、平移、旋转、1:1、EXIF、幻灯片、文件夹、标签、搜索与裁剪编辑。
12. **属性抽屉（双 Tab：`信息` | `版式`）**：抽屉宽度 `320–340px`，顶部以轻分段控件切换两页：
    - **信息**：保留定稿状态卡、比赛/题目纯内容元数据（含比赛语言，决定题面语言与限值措辞）、单题限值覆写（左侧细竖条标出覆写 + 一键还原）与「素材 N 个」入口；
    - **版式**：
      - **比赛上下文**：顶部为模板选择（支持切换工作区 `templates/*.typ`、从预设种子添加新模板，或一键「独立为本场专属模板」生成 `contests/<id>/template.typ` 并随时恢复引用工作区模板）；下方 **100% 由当前模板的 `#let schema` 动态渲染**（无硬编码通用开关），支持 9 种控件（`bool` / `enum` / `string` / `lines` / `number` / `length` / `color` / `font` / `image` 选图导入），每个 schema 分组直接作为带 `1px` 分割线的一级区块，与上级默认不同的字段用左侧细竖条标出并提供一键还原；若有单题级（`scope: "problem"`）字段，同步展示当前题在该比赛中的版式覆写；
      - **单题上下文**：只编辑本题在 `problem.toml` 里的单题级模板参数，顶部显示当前沿用的工作区默认模板并提供「调整工作区默认版式」跳转入口，避免在单题视图误改全局配置；
      - **所有模板平等可编辑**：任何生效模板都可直接「在外部编辑器中打开模板」（保存后 `notify` 热刷新预览），并提供「新建模板副本」与「自定义样式代码」入口；界面文案不暴露内部路径，也不在应用内做 Typst IDE。已定稿的比赛下所有控件均呈只读态。

## 9.2 开发者诊断窗口（Phase 6B）

- **主窗口零污染原则**：主工作区（含「设置 → 关于」）不出现 FPS、延迟 HUD、`Chrome Trace`、`Perfetto` 等开发者术语或实时指标控件；所有可观测性能力统一收进独立的 NSH 0.7 多窗口「XCPC 诊断」。
- **视觉与壳层一致**：复用主窗口的 44pt `<TitleBar>`（左状态点与标题、中 `指标 / 追踪 / 日志` 短分段标签、右时间窗与控制按钮及原生窗口控件），共用全套浅色/深色/`theme.toml` Token，窗口标题通过 `useWindowTitle` 随界面语言实时同步，按钮瞬态确认保持固定最小宽度零抖动。
- **高密度与术语豁免**：诊断窗口内允许出现精确技术术语（`build_document`、`rasterize_cached`、IPC、INP、P95、Span、Perfetto）及面向排障的高信息密度；依然遵守 `tabular-nums`、无 `·` 装饰分隔与可信数据呈现（离散事件脉冲不连跨分钟斜线、空闲帧不计掉帧）。
- **入口与生命周期**：通过 `Cmd+K`（「打开性能与诊断窗口」）、全局快捷键 `Ctrl+Shift+D` 或启动环境变量 `XCPC_O11Y=1` 唤起；关闭主窗口时一并关闭并退出；关闭诊断窗口立即退回常态轻量环形缓冲。

## 10. 明确不做（界面与品牌）

轮播引导、每次启动的独立启动页或启动动画、slogan、常驻版本底栏、toast、按用户行为触发的主动提示、自定义改键、特定日期彩蛋、里程碑动效、icon 上的字母、ICPC 官方三色块组合。
