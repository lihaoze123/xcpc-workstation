# XCPC 常见错解与对抗造数分类学（Mistake Taxonomy）

本表供出题阶段（特别是 [`wrong-gen/SKILL.md`](./wrong-gen/SKILL.md)）逐项排查：针对本题涉及的算法领域，先识别高发错因，再据此设计定向错解与对应 hack 数据。

---

## 1. 整数溢出（Overflow / int32）

| 常见错误模式 | 对应 Hack 造数策略 |
| :--- | :--- |
| 累加和、乘积、平方或答案超过 `int`（$2^{31}-1$）未开 `long long` | 全最大值（如 $n = 10^5, a_i = 10^9$），使真实答案 $> 2^{31}-1$ 且截断后不巧合相等 |
| 中间值超过 `long long`（$2^{63}-1$）未及时取模或未用 `__int128` | 构造 $a \times b \ge 2^{63}$ 或三数连乘接近 $10^{18}$ 的满值数据 |
| 减法取模漏加 `MOD` 导致负数结果（`(a - b) % MOD`） | 构造大量 $a < b$ 且跨模数边界的询问/转移 |
| 位运算误写 `1 << k`（32 位有符号移位未写 `1LL << k`） | 覆盖 $k \ge 31$ 的高位场景 |

---

## 2. 贪心陷阱（Greedy Traps）

| 常见错误模式 | 对应 Hack 造数策略 |
| :--- | :--- |
| 单关键字排序（只按左端点/右端点/长度/权值/比值排序） | 构造「局部最大但阻塞全局最优」的小反例（如 $2+2$ 优于 $3+1$），并扩成满数据重复嵌入 |
| 忽略相等元素的平局处理顺序（tie-breaking） | 构造大量键值相等、但次关键字不同且影响后续决策的数据 |
| 未做反悔贪心（只顺推不回退） | 构造先选小代价、后出现高收益需替换前序选择的交替序列 |
| 假二分单调性 / 假三分凹凸性 | 构造多峰、平台段（连续相同值）或非单调转折点 |

---

## 3. 边界与差一错误（Off-by-one / Boundary）

| 常见错误模式 | 对应 Hack 造数策略 |
| :--- | :--- |
| 漏处理极小规模（$n = 1$、$m = 0$、空操作、单字符） | 手写 `edge` 测试覆盖每个维度的绝对最小值 |
| 全相等 / 全 0 / 全负数 / 严格递增 / 严格递减 | 单独造全同值、全极小值、严格有序与逆序数组 |
| 答案恰好落在第 1 个或最后 1 个元素、或区间端点开闭错位 | 构造唯一最优解位于首尾、边界恰好卡在 $L$ 或 $R$ 的数据 |
| 二分边界 `l + 1 < r` / `mid` 向上或向下取整死循环 | 覆盖答案恰好等于 `min_ans`、`max_ans` 与相邻差 1 的情况 |
| 无解判断错误或输出 `-1`/`NO` 后继续输出残余内容 | 专门构造无解测试（以及多测中「有解—无解—有解」交替） |

---

## 4. 图与树退化结构（Graph & Tree Degenerates）

| 结构 | 常见错误模式 | 对应 Hack 造数策略 |
| :--- | :--- | :--- |
| **长链（Chain）** | 假启发式合并、递归 DFS 爆栈、按深度暴力跳 LCA、$O(\text{depth})$ 退化 | 满 $n$ 长链（顺序编号 + 随机重标号防按编号偷鸡） |
| **菊花图（Star）** | 遍历邻居再嵌套遍历邻居 $O(\sum \deg^2)$、树形 DP 合并未控制上界 | 满 $n$ 菊花（中心节点分别取 `1`、`$n$`、随机点） |
| **扫帚图（Broom）** | 只卡链不挂、只卡菊花也不挂的复合复杂度漏洞 | 长度 $n/2$ 的链尾部接大小 $n/2$ 的菊花 |
| **完全二叉树 / 毛毛虫树** | 假定链剖分轻链极少或重心唯一 | 满二叉树 + 链上挂大量长度为 1–2 的短枝 |
| **不连通图 / 孤立点 / 森林** | 只从节点 `1` 跑一次 DFS/BFS、未处理孤立点 | 多个连通分量 + 若干孤立点，答案不在含 `1` 的分量中 |
| **重边 / 自环 / 负权（若题意允许）** | 邻接矩阵覆盖、Dijkstra 处理负权、未去重导致计数翻倍 | 在题面允许前提下显式构造重边、自环与零权边 |
| **二分图 / 网格图 / 稠密图** | 强行假设一般图稀疏，或 SPFA 在网格图/菊花链上退化 | $k \times (n/k)$ 网格图、带负/小权捷径的 SPFA 反例图 |

## 5. 哈希碰撞与容器卡常（Anti-Hash / Container Blowup）

| 常见错误模式 | 对应 Hack 造数策略 |
| :--- | :--- |
| `std::unordered_map` / `unordered_set` 使用默认哈希 | 按 GCC 质数桶表（如 `107897` / `126271` 倍数）构造全碰撞键序列，将其打成 $O(n^2)$ |
| 字符串自然溢出哈希（`unsigned long long`） | Thue-Morse 序列（长度 $2^k$，在任意奇数底数下前缀哈希碰撞） |
| 常见单模字符串哈希（如 $10^9+7$ / $998244353$ + 常见 base） | 构造已知碰撞串对或双倍长度生日攻击集合（必要时针对常见单模构造） |
| `std::set` / `std::map` 误用 `std::lower_bound(s.begin(), s.end(), x)` | 满规模有序查询（`std::lower_bound` 在非随机访问迭代器上是 $O(n)$！） |

---

## 6. 浮点精度与误差（Precision & EPS）

| 常见错误模式 | 对应 Hack 造数策略 |
| :--- | :--- |
| 用 `float` 或 `double` 做大数加小数导致有效位丢失 | 构造数量级跨度极大（如 $10^9 + 10^{-4}$）的输入 |
| 计算几何共线/近乎平行点集导致叉积误差或除零 | 构造三点共线、近乎重合、大坐标差微倾斜线段 |
| 实数二分用 `while (r - l > eps)` 而非固定迭代次数 | 答案极大（如 $10^9$）时 `r - l` 无法小于 `1e-9` 导致死循环 TLE |
| 输出 `-0.0` 或未设置足够小数位数（默认 `cout` 仅 6 位有效数字） | 构造答案接近 0（易出 `-0.0`）或需完整 9 位小数精度的用例 |

## 7. 复杂度退化与卡常（Complexity Blowup）

| 常见错误模式 | 对应 Hack 造数策略 |
| :--- | :--- |
| 朴素 $O(n^2)$ / $O(nm)$ / $O(n\sqrt{n}\log n)$ 冒充正解 | 满规模压测，保证标程 ≤ 50% 时限而次优解显著 TLE |
| 并查集漏写路径压缩或按秩合并 | 构造链式连续合并 + 反复查询最深叶子 |
| SPFA 替代 Dijkstra 跑非负权最短路 | 经典链 + 菊花 / 网格 + 大边权松弛反例，令松弛次数达 $O(nm)$ |
| 线段树 / 树状数组常数爆炸、无谓 `std::vector` 频繁动态扩容 | 满规模高频修改与查询交替数据 |
| 递归深度 $O(n)$ 导致栈溢出或函数调用开销过大 | 满 $n$ 单链/退化树 |

---

## 8. 多组测试脏状态（Multi-test Dirty State）

| 常见错误模式 | 对应 Hack 造数策略 |
| :--- | :--- |
| 全局数组、邻接表、标记数组、`ans` 变量未在组间重置 | 第 1 组设大 $n$ 且产生非零/大答案，第 2 组设小 $n$ 或无解 |
| 每组调用 `memset(a, 0, sizeof(a))` 导致 $O(T \cdot N_{\max})$ 超时 | **大 $T$ 小 $n$** 满压测（如 $T = 10^5, n = 1$，$\sum n$ 合法但 $T \cdot N_{\max} = 10^{10}$） |
| 判定无解后提前 `break` 未读完当前组剩余输入 | 第 1 组在前缀即触发无解、后面仍有大量数据，紧跟第 2 组正常数据 |
| 离线排序/离散化数组未清空或沿用上一组长度 | 连续多组规模递减（$n = 100 \to 50 \to 10 \to 1$） |
