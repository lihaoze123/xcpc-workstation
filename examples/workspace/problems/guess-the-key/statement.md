这是一道交互题。

管理员手里有一把编号为 $x$ 的钥匙，$1 \le x \le n$。你每次可以猜一个编号 $y$，管理员会回答：

- `<`：$x < y$；
- `>`：$x > y$；
- `=`：猜中了，此时你的程序应立即结束。

你最多可以猜 $\lceil \log_2 n \rceil + 1$ 次。

## 交互

首先读入一个整数 $n$（$1 \le n \le 10^{18}$）。

每次猜测输出一行 `? y`，然后读入一个字符作为回答。每次输出后请刷新输出缓冲区，例如 C++ 中使用 `std::cout << std::flush`。

## 提示

样例中左边是交互库的输出，右边是你的程序的输出，空行只为对齐，实际交互中不存在。
