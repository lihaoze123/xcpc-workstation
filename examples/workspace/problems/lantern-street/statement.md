元宵节到了，长度为 $L$ 的街道上要挂 $k$ 盏灯笼。街道上已经有 $n$ 个挂钩，位置为 $x_1 < x_2 < \cdots < x_n$，灯笼只能挂在挂钩上。

为了美观，你希望**相邻两盏灯笼之间的最小距离**尽可能大，即最大化
$$
D = \min_{1 \le i < k} \left( p_{i+1} - p_i \right),
$$
其中 $p_1 < p_2 < \cdots < p_k$ 是选中的挂钩位置。

![街道示意](assets/street.svg)

## 输入格式

第一行三个整数 $n, k, L$（$2 \le k \le n \le 10^5$，$1 \le L \le 10^9$）。

第二行 $n$ 个整数 $x_1, \ldots, x_n$（$0 \le x_1 < \cdots < x_n \le L$）。

## 输出格式

输出一个整数，表示 $D$ 的最大值。

## 样例解释

第一组样例中，选择位置 $0, 4, 8$，最小距离为 $4$。

## 子任务

| 子任务 | 分值 | 约束 |
| :---: | :---: | :--- |
| 1 | 30 | $n \le 20$ |
| 2 | 30 | $n \le 2000$ |
| 3 | 40 | 无特殊约束 |
