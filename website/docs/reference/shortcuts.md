# 桌面端快捷键速查

在桌面端任意界面按下 `Ctrl+/`（macOS 为 `⌘+/`）可随时呼出带实时搜索的快捷键速查浮层，也可在 **「设置 → 快捷键」** 中浏览完整列表。

> **跨平台修饰键说明**：下表以 Linux / Windows 下的 `Ctrl` 为主写法；在 macOS 上，凡标注为 `Ctrl` 的组合键（除明确标注的 Vim `Ctrl+[`、`Ctrl+r` 与诊断窗口 `Ctrl+Shift+D` 外）均自动映射为 `⌘`（Command）。

## 全局与导航

| 操作 | 快捷键 | 作用域与说明 |
| :--- | :--- | :--- |
| 打开命令面板 | `Ctrl+K` | 全局。支持中英文与拼音检索，按使用频率（Frecency）排序。 |
| 打开快捷键速查 | `Ctrl+/` | 全局。 |
| 切换到「题库」 | `Ctrl+1` | 首页主导航。 |
| 切换到「比赛」 | `Ctrl+2` | 首页主导航。 |
| 切换到「模板」 | `Ctrl+3` | 首页主导航（若 `workspace.toml` 设置 `snippets = false` 则隐藏，后续空间键位顺移）。 |
| 切换到「训练」 | `Ctrl+4` | 首页主导航（若 `workspace.toml` 设置 `training = false` 则隐藏，后续空间键位顺移）。 |
| 切换到「工具」 | `Ctrl+5` | 首页主导航。 |
| 切换到「设置」 | `Ctrl+6` | 首页主导航。 |
| 打开已有工作区 | `Ctrl+O` | 全局。 |
| 关闭浮层或返回上级 | `Esc` | 全局。 |

| 操作 | 快捷键 | 作用域与说明 |
| :--- | :--- | :--- |
| 新建题目 | `Ctrl+N` | 题库列表（非只读工作区）。 |
| 新建比赛 | `Ctrl+Shift+N` | 比赛列表（非只读工作区）。 |
| 聚焦搜索框 | `Ctrl+F` | 题库列表。 |
| 列表下一项 | `j` | 题库、比赛与模板列表（输入框未聚焦时）。 |
| 列表上一项 | `k` | 题库、比赛与模板列表（输入框未聚焦时）。 |

## Vim 模式（实用子集）

Vim 模式默认关闭，可在 **「设置 → 外观 → 编辑器排版 → Vim 模式」** 中一键开启。开启后编辑器顶部工具栏右侧显示当前模式徽标（`NORMAL` / `INSERT` / `VISUAL` / `V-LINE`）。

| 操作 | 按键 | 适用模式 |
| :--- | :--- | :--- |
| 返回 Normal 模式 | `Esc` / `Ctrl+[` | Insert / Visual |
| 移动光标与按词跳转 | `h j k l` / `w b e` / `0 $` / `gg G` | Normal / Visual |
| 进入 Insert 模式 | `i a I A o O` | Normal |
| 删除、复制与粘贴 | `x` / `dd` / `yy` / `p P` | Normal |
| 撤销与重做 | `u` / `Ctrl+r` | Normal |
| 字符 / 行可视选择 | `v` / `V`（配合 `d` `y` `c`） | Normal |
| 内部文本对象 | `vi` / `ci` / `di` / `yi` + `w` `$` `()` `""` `''` `` `` `` | Normal / Visual |
