# 开发者诊断与可访问性

XCPC Workstation 遵循「主工作区零技术噪音」原则，将全部实时性能指标、跨线程调用链与结构化日志收口至独立多窗口诊断面板；同时在桌面端内置完整的键盘焦点环与三档 `prefers-reduced-motion` 动效降级策略。

---

## 1. 独立多窗口 `nsh-o11y` 开发者诊断面板

### 唤起方式

- 快捷键：`Ctrl+Shift+D`（打开或聚焦独立「XCPC 诊断」窗口）；
- 命令面板：按 `Ctrl+K`，搜索「打开性能与诊断窗口」（支持关键词 `o11y` / `diagnostics` / `perf` / `trace` / `诊断` / `性能`）；
- 启动环境变量：以 `XCPC_O11Y=1` 启动桌面端，应用启动时自动打开诊断窗口。

### 两级采样与常态零开销

诊断系统分为两级运行模式，确保日常使用时对编辑与预览零负担：

1. **常驻内存环（Always-On Ring，默认开启）**：**零 `rAF` 轮询、零磁盘写入**。仅在内存中维护容量上限 5,000 条的 `LogStore`，低开销记录慢 IPC（`> 50 ms`）、未捕获异常以及 Rust 侧慢/错误日志；打开诊断窗口时一次性拉取展示。
2. **实时诊断模式（Live Diagnostics）**：在诊断窗口打开期间（或通过 `XCPC_O11Y=1` 自动打开）激活；若启动时显式设置 `XCPC_TRACE=1`，则会同时开启底层 Rust 与前端的 Trace 录制。窗口打开后按 `1000 ms`（1 秒）周期轮询并向 4 个实时时间序列推送数据，关闭诊断窗口后立即停止轮询（未设置 `XCPC_TRACE=1` 时同步停止 Trace 与帧率采样）。

### 三大诊断视图

#### 指标（Metrics）

提供 4 张通过 `createChartSync()` 联动缩放的时间序列图（支持 `1m` / `5m` / `15m` 时间窗，拖拽框选、滚轮缩放、双击或点击「复位缩放」同步复位）：

1. **帧率与卡顿**：帧间隔（`ms`，过滤 `> 120 ms` 的空闲间隔，活跃尖峰上限封顶 `50 ms` 并在右上角标注真实峰值）与掉帧数，附 `120Hz (8.33 ms)` / `60Hz (16.67 ms)` 参考阈值线。
2. **排版与预览管线**：离散脉冲展示 `build_document`（编译）与 `rasterize_cached`（光栅化）耗时，右上角实时显示最近值与 `P95`，附 `50 ms` 慢阈值线。
3. **IPC 与交互响应**：离散脉冲展示前端↔Rust `IPC` 与交互延迟 `ux.inp.*` 耗时及 `P95`。
4. **缓存与内存**：像素缓存占用（`MB`，附预算上限阈值线）与缓存命中率（`%`）。

#### 追踪（Traces）

- **跨线程 Span 瀑布图**：合并展示 Rust Core 线程与前端 UI 线程的完整 Span 树，支持小地图（Minimap）、关键路径高亮与点击 Span 查看属性详情。
- **防跳动列表与筛选**：支持按「全部 / `>50ms` / `INP` / 错误」筛选；当列表已有记录时，新到达的 Trace 会暂存于顶部「N 条新记录（点击刷新）」提示条，避免行位跳动打断阅读。
- **命名基线与同场景对比**：点击「存为基线」可将当前 Trace 固化为命名基线；切换至「基线对比」即可并排 Diff 优化前后的 Span 耗时差异（内置同场景校验，防止跨场景误对比）。

#### 日志（Logs）

- 内置日志量直方图与虚拟化日志列表，支持按 8 个子系统筛选：`engine`、`convert`、`judge`、`plugin`、`sync`、`ipc`、`ui`、`desktop`；
- 选中任意日志条目可一键「复制日志」（格式化 JSON，包含时间戳、级别、子系统、消息与属性）。

### 导出 Perfetto JSON

点击诊断窗口顶栏的 **「导出 Perfetto」**，可将当前录制的 Rust + 前端统一时间轴保存为 Chrome Trace JSON 文件，直接拖入 [Perfetto UI](https://ui.perfetto.dev/) 进行离线火焰图分析。桌面端退出或切换工作区，以及基准测试（如 `preview_bench`）场景下，也可通过环境变量 `XCPC_TRACE=1 XCPC_TRACE_OUT=trace.json` 将 Rust 侧 Trace 事件直接落盘。

## 2. 关于页：一键复制诊断信息与字体许可

反馈 Bug 或排查环境问题时，无需手动收集系统信息：

1. 前往 **「设置 → 关于」**；
2. 点击 **「复制诊断信息」**，剪贴板将写入标准化纯文本摘要：
   ```text
   XCPC Workstation <version>
   Commit: <short-commit>
   Build Date: <build-date>
   Platform: <os> (<arch>)
   Fonts: UI=<ui-font-source>; Typesetting=<typesetting-font-source>
   ```
3. 同页下方同时提供「开源致谢」与内嵌字体（Inter、JetBrains Mono、Latin Modern）的「字体许可」声明。

## 3. 可访问性与动效降级

### 全键盘导航与焦点环

- 桌面端全部可交互控件（按钮、列表行、分段控制器、菜单项、标签页与诊断面板控件）统一覆盖高对比度 `FOCUS_RING` 焦点环，支持纯键盘 Tab 浏览与确认操作。
- 截断文本统一使用 `TruncText`，鼠标悬浮或聚焦时提供完整内容提示。

### `prefers-reduced-motion` 三档降级策略

桌面端动效通过 `tokens/motion.ts` 集中管理（常态下采用温润物理弹簧，阻尼比 $\zeta \in [0.872, 0.895]$、过冲 $\le 1\%$），并实时响应操作系统的「减少动态效果（`prefers-reduced-motion`）」设置，按三档语义精细降级：

| 动效类别 | 常态表现 | 开启 `prefers-reduced-motion` 后 |
| :--- | :--- | :--- |
| **空间位移与缩放**（工作室切换、侧栏抽屉、弹窗缩放、按钮按压缩放、Toast 入场位移动效） | 物理弹簧位移 / `scale(0.96 → 1)` / `scale(0.97)` | **降级为纯透明度淡入淡出**（`120 ms`）或仅保留色彩反馈，彻底取消位移与缩放。 |
| **指示条与布局重排**（导航/分段滑块、折叠箭头旋转、`animateLayout` 列表重排、程序化滚动） | 弹簧滑动或平滑过渡 | **瞬时到位**（`0 ms` 无动画，避免视线追踪负担）。 |
| **色彩与纯透明度反馈**（悬停/选中态变色、遮罩淡入淡出） | `100–120 ms` 标准缓动 | **完整保留**，确保交互状态变化仍清晰可辨。 |

> 开发者在本地调试动效时，可在开发构建中设置环境变量 `XCPC_MOTION_SLOW=<倍率>`（如 `XCPC_MOTION_SLOW=4`）等比慢放所有时长与弹簧（保持阻尼比 $\zeta$ 不变）；该开关在 Release 构建中恒为 `1`。
